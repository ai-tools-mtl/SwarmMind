## D1 数据加载与并发规则

现状澄清（采纳复审指正）：app.js:179-194 为 **Promise.all 聚合三接口+单一 S.snap+统一 render()**。v3 规则：

- **每资源独立 seq**：`S.seq = {nodes:0, tasks:0, directory:0}`；每资源每次请求发起时 `++seq` 并随请求记录；响应返回时仅当 `响应序号 === 该资源当前 seq` 才提交快照（防旧覆盖）。Promise.all 聚合结构保留，但提交路径按资源拆分。
- **部分成功**：任一资源失败不 reject 其他——每资源独立 try/catch，失败资源保留旧快照+该资源新鲜度标记「（陈旧）」；tasks 持续成功不会掩盖 nodes 失败（新鲜度按资源记录，顶栏显示**最陈旧**资源的状态）。
- **loadAll() 全入口统一**：进页/轮询 tick/手动刷新共用同一提交函数（含 seq 校验+结构校验），无旁路。
- **changed 计算与渲染**：资源提交后与旧快照浅比较（节点在线位/任务集指纹）；有变才 render，无变只更新新鲜度小字（新鲜度小字自身独立 DOM 更新，不经 render()）。
- **结构校验**：非 200 或关键字段缺失（nodes 数组/tasks 对象）不提交。
- 超时挂起：12s 无成功响应的资源标陈旧（AbortController 12s 中止在途请求）。

## D3 层生命周期状态机（全入口）

状态：`closed → opening → open → closing → closed`（另 `hidden` 为外壳常驻但无内容的静默态）。

**全部入口清单（v3 明确，实施时逐一对齐）：**
| 入口 | 现状行为 | v3 归一 |
|---|---|---|
| openLayerPlain（弹层/向导/说明） | 重建 #layer 内容 | 状态机 open（外壳常驻，只换 .modal 内容） |
| closeLayer | 同步清空 | closing→280ms 后 hidden（generation 校验） |
| syncDrawer | 无 drawer 时清层、有则重建 | open 分支增量更新；closed 时不碰层 |
| 登录/退出登录渲染 | 直接清层 | 统一走 closeLayer 生命周期（登出时 generation++ 立即废弃在途回调） |
| Esc 全局 handler | 直接清层 | 仅 open 态响应，触发 closeLayer；closing/hidden 忽略 |

- **generation 校验**：`S.layerGen` 递增；任何延迟回调（清理/inert 释放/焦点返回）执行前校验 gen，不符即放弃。旧关闭回调不得修改新层的 DOM/焦点/inert。
- 打开即 `++gen`（新层生效，旧清理作废）；替换层内容（向导步进）不改 gen（同一逻辑层）。
- 每次转换有唯一 owner 函数（`layerTransition(state)`），禁止入口直接操作 #layer innerHTML（grep 检查：#layer innerHTML 赋值仅存在于状态机内）。

## D4 焦点与背景隔离

- **inert 范围**：`#app` 主容器 + 顶栏（#logout 在 #app 外——index.html:10-16，单独列入）；即「背景全部操作区」。层自身（#layer）不加 inert。
- **释放时机=关闭开始**（closing 进入即释放 inert 与焦点约束）——保证 FE-14 关闭动画期侧栏可点，与 D3 状态机一致。
- 焦点循环（Tab Trap）仅在 open 态生效；closing 即停止拦截。
- `aria-labelledby` 关联层内标题（纠正 v2 的 aria-modal 表述）；向导换步焦点移入新步骤首个可交互元素；层内无可交互子控件时焦点落在层容器本身（tabindex=-1）。
- 关闭焦点返回稳定目标：触发元素存活性检查→失存则返回侧栏当前页签按钮。
