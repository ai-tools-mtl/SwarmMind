- 验证板/请求登记为进程内存态或 data_dir 单文件（重启语义各自如实）；hub 下发轮不经 node 侧队列守卫（RFC §4 既有残留，hub 侧判定已补）；ack 超时回退竞态窗（留档可对账）；取消任务与目标轮结果到达次序不保证（双路记账先到保留）；检测层粗检语义（不校验语法，裁决口径）。
