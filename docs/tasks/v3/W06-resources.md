## 检测模型与变更原则

四层分别记录`installed/config_recognized/execution_ready/call_allowed`、检查来源/时间/能力版本、未验证原因；未运行真实模型探针不能声称账号/额度可用。命令路径存在/--version成功是安装证据，配置文件结构可识别不代表登录成功。显示“执行前置检查通过（模型未验证）”或“用户明确探针通过”，不合并成一盏绿灯。

扫描仅使用主人已配置命令或明确受控PATH/标准安装候选，子进程超时/输出上限/干净环境，不运行可疑shell拼接。识别HOME只返回是否可用与引用，秘密内容永不返回。真实agent探针需人工显式动作、独立目录、额度说明；无权限工具不能自动yolo。

agent配置至少command/adapter/args/cwd/config_home引用/permission/timeout/允许环境；编辑预览差异后原子保存，热生效/需重启分别说明。在途绑定/旧会话不自动变更；不兼容续聊拒绝，关闭远端exposed对已接受任务的现行语义保持，新的本机调用开关拒绝新请求不杀在途。

## 拟定REST/MCP

| 操作 | REST | MCP/权限 |
|---|---|---|
| 扫描/登记/改配置 | POST /api/v1/local/agents/discover；复用/local/config与agents/reload保存；按需新增登记预览 | 本机主人专属，涉及执行配置与HOME授权，SPEC逐端点人工豁免 |
| 无秘密目录/状态 | 复用GET /api/v1/agents及Hub /directory；扩检测摘要、scope/会话能力 | swarmmind_agents两backend同步输出，Hub只有Node明确开放的投影 |
| 真实运行检测 | POST /api/v1/local/agents/{name}/probe | 主人显式操作豁免；调用额度/工具须预告，不允许任意命令入参；检测结果只影响健康摘要，不改执行权限 |
| 默认管家 | 调整现有prime/declare与orchestrator标记，保持W02迁移约定 | 人工角色配置豁免；已开放MCP与已有空间负责人不被暗中改动 |

Hub没有扫描本机agent按钮，也不从公网服务环境推断外部安装；P05只读目录/提示源节点修复。资源目录为配置事实，不授予租约。role声明冲突/旧名字推断fallback要显示来源，W06-03制定淘汰/兼容策略，不能展示“唯一管家已生效”而实际多声明。
