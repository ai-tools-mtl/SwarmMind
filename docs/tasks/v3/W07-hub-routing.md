## REST/MCP映射与边界

| 能力 | 当前/拟定接口 | MCP与校验 |
|---|---|---|
| 发现与远程会话 | 已有/directory、/nodes、/sessions与turns | nodes/agents/session_create/send/list/status复用，旧关闭人工豁免不破坏 |

| 版本范围 | W02 /api/v1/capabilities，目录能力投影 | swarmmind_capabilities；返回当前中心与目标Node支持情况，不表示私有历史可读 |
| 节点接入/停用 | 复用/api/v1/nodes/enroll*及Node setup*，如缺停用动作明确补主人接口 | 现行凭据/装机人工豁免；普通agent不能给自己增加Node接入凭据 |

中心空间scope固定为hub:<id>，成员必须来自当前开放目录；Node执行前验证request origin、owner/term与会话绑定。中心创建的线程与本机私人线程不能同ID双写；本机旧线程不被MCP全网列表默认泄露。会话仍由执行Node掌握原生ID，不把传输epoch当原生线程身份。

请求/结果在中心和Node记录同一operation ID、space/session/turn引用；在途先登记再send、迟到结果验证来源后消费。Hub分配请求键，不信远端自报mid；旧term拒绝新派发，但已接受轮次事实可落账，不触发暂停空间的下一步。
