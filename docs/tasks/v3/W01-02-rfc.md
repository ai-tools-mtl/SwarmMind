# W01-02 RFC：会话操作服务（sessionop）定案

状态：定案（依 W01-01 基准 §3/§4/§5/§6；2026-10-30）。
效力：本文件是 W01-02 实现与测试的定案记录；与任务书冲突以任务书为准并回改本文件。

## 0. 范围与不动点

- 新包 `internal/node/sessionop`，导出类型 `sessionop.Service`；在 sessionx 内核与 node ledger 之上编排。
- **sessionx 内核零改动**：四原语（Create/CreateWithID/Send/Close）、写者门 FIFO、墓碑防复活、绑定守卫、门表上限语义全部保持。本批对 sessionx 无任何纯加法（取消哨兵等需求经 ledger 终态与执行证据分类满足，无需新增内核错误）。
- **普通任务路径零行为变化**：sessionop 未装配（Config.SessionOps == nil）时，全部新增判定短路，行为与今天逐字节一致（既有测试零删改全绿的结构性保证）。
- HTTP/MCP 接线（localapi 状态码投影、hub 侧、cmd/node 装配）属 W01-03，本批只交付原语与 service 内部接线。

## 1. 创建请求 ID（持久登记）

- 存储：`data_dir/session_requests.json`，信封 `{version, requests:[{request_id, session_id, turn_seq, payload_hash, accepted_at}]}`；全量互斥重写，原子写纪律同 sessions.json（独占创建 tmp + fsync + rename，0600，目录 fsync 尽力而为）；时间一律 UTC（protocol.NowUTC）。
- 原语（仅登记与解析，无 HTTP）：
  - `ResolveRequest(requestID, sessionID, turnSeq, payloadHash) (rec, dup, err)`：互斥锁内查登记——未登记则登记并返回 dup=false（调用方据此继续受理）；同键且 (session_id, turn_seq, payload_hash) 三元组全等 → 返回原登记 dup=true（同键同文返回原受理）；三元组任一不同 → `ErrRequestConflict`。
  - `LookupRequest(requestID) (rec, ok)`。
- 落盘失败：内存登记不保留（盘为真相，重试重新登记），错误如实上抛——绝不虚报登记成功（N07）。
- request_id 为空：原语层拒绝（invalid），可选语义由 W01-03 接线层裁量。

## 2. 有界串行队列（默认 16/会话）

- 口径：逐会话统计账本中**非终态已受理轮**——`Task.Session != nil && SessionID==sid && TurnSeq>0 && State != finished`（accepted+started，含在途与排队；close 任务 TurnSeq=0 不计；终态 cancelled/failed/needs_review 不计）。
- 上限：`Options.QueueLimit`，0 → 默认 16；非终态计数已达上限再受理即拒。
- 原子性：判定置于 `SubmitSessionTurnLocal` 的 `localMu` 互斥段内、`AcceptOrigin` **之前**（沿用 T2-R1 建议 3 的「推导→守卫→入账」同锁域模式）——并发本地提交不可能「检查后入账」竞态；拒绝即零副作用：无账本条目、高水位不推进、CLI 不执行、内核零触碰（N01）。
- 满队列错误：`ErrQueueFull`（错误码 `turn_queue_full`；409 语义，HTTP 投影 W01-03 接线）。
- 残留声明（如实）：hub 经 task_offer 下发的会话轮入账不经 localMu（既有投递链结构），本批不改变该路径；hub 侧队列上限按基准 §5 由 W01-03 在 hub 落库前判定。node 侧计数按账本快照实时反映两类来源的合计。

## 3. 取消原语 CancelTurn(sessionID, seq) 与三竞态收敛矩阵

取消**意图登记先于触发**（对齐 AGENTS.md「登记先于 Send」纪律：handle 在受理互斥段内 BeginTurn，执行 goroutine 在 execute 入口绑定取消开关）。取消**终态一律由执行 goroutine 依自身位置与证据记账**（单写者，杜绝两个 goroutine 竞写终态）；CancelTurn 只登记意图、触发执行 ctx 取消、等待收敛、按账本终态如实出回执。

**证据口径**（spawn 边界 = CLI 进程真实启动）：
- 内核轮行不存在（turn==nil：调度/内核门排队期弃队）→ 未 spawn；
- 内核轮行 `ExitCode==ExitCodeNotRun` 且错误前缀 `protocol.CodeTimeout + ":"`（runner 治理「context 已取消或到期，进程已整组终止」+ ReapProcessGroup 已收尾）→ 已 spawn 且**有停止证据**（进程组已终止并回收，无孤儿）；
- 内核轮行 `ExitCode==ExitCodeNotRun` 但无治理标记（如 spawn_failed）→ 进程从未存在，属自然失败（先到保留）；
- 其余（真实退出码）→ 自然终态（先到保留）。

**收敛矩阵**：

| 取消到达时轮的位置 | 收敛 | 账本终态（TaskResult） | 平台序号 | CancelTurn 返回 |
|---|---|---|---|---|
| 未受理（无条目，高水位 < seq） | 不可取消 | 无 | 不消耗 | `ErrTurnUnknown`（turn_not_found） |
| 已受理排队（accepted，等调度/并发槽/内核门） | 确定性终止：本轮绝不 spawn | finished/cancelled，Error=`turn_cancelled_queued` | **消耗**（高水位不回退） | 回执 queued |
| 执行中（进程组在跑） | ctx 取消 → runner 治理整组 kill+Wait+Reap | finished/cancelled，Error=`turn_cancelled_executed` | 已消耗 | 回执 executed |
| 执行中但停止证据缺失（防御：turn 非空、ExitCode==-1、无治理标记） | 不虚报已停止 | finished/**failed**，Error=`turn_cancel_outcome_unknown`（待核对，绝不记成功） | 已消耗 | 回执 unknown |
| 已自然终态（completed/failed 自然路径，含迟到取消） | **先到保留**，取消不改写 | 保持自然终态 | 不变 | `ErrTurnFinished`（已完成不可取消，附实际状态） |
| 已取消终态 | 幂等重放 | 不变 | 不变 | 返回原回执（同 queued/executed） |
| 取消触发但终态落盘失败（N07） | 不虚报 | 保持非终态（如实） | 已消耗 | `ErrCancelUnconfirmed`（取消已触发、终态未落盘） |

- 竞态仲裁全部落在账本「先到为准」（MarkFinished/MarkStarted ErrWrongState 收敛）+ 单执行 goroutine 依位置分类，双取消/取消对终态/取消对受理均确定。
- 排队取消的轮**消耗序号**：受理即推进 `SessionTurnHW`（与 hub 口径一致，T2-R2 N4 延续）；同 seq 重放（hub 显式轮号，W01-03）对 cancelled 行返回原回执——node 侧由账本条目 + ErrDuplicate 保证只执行一次、回执稳定。
- 与 hub task_cancel 的关系：sessionop 意图未登记时沿既有 cancelled/user_cancelled 收尾（零变化）；意图登记后按本表分类记账（两类取消均为取消类终态，不冲突）。
- 服务关闭与取消竞态：关闭分支胜出 → 沿既有 needs_review/node_restarted_midway，CancelTurn 如实回报该终态；取消分支胜出 → 按本表。

## 4. 关闭在途防护

- `CloseSessionLocal` 在 `localMu` 互斥段内判定：存在该会话非终态受理轮（口径同 §2）→ `ErrCloseInFlight`（错误码 `close_in_flight`，409 语义，指向取消/等待），不触内核。
- 防护与受理同锁域：判定通过后才释放 localMu 调内核 Close——本地新轮不可能「检查后插入」（本地受理必须拿 localMu）；此刻无非终态轮 ⇒ 内核无在途轮操作 ⇒ Close 立即拿门落定。
- 内核墓碑语义不动：映射未发布/无门的关闭仍落持久化墓碑；关闭后创建拒绝（ErrSessionClosed）不复活（N04 回归内核既有测试）。
- 残留声明：hub 派发轮不受 localMu 约束，检查与 Close 之间窗口内的 hub 新轮由内核门串行与 ErrSessionClosed 显式失败收敛（无复活，仅有显式失败轮）；hub 侧 close_in_flight 判定按基准 §5 由 W01-03 落库前实现。

## 5. 工作区授权与真实路径互斥

- 授权：`Options.AllowedWorkspaceRoots`（空 = 放行，保持现状）。判定：cwd 与根各经 **`resolveWorkspace`**（sessionop 内同一函数同一策略，codex 终审定案）归一为真实路径——优先整体 EvalSymlinks；失败（路径尚不存在等）向上取**最近已存在祖先**解析真实路径后拼接剩余段（Join 内建 Clean，祖先为根 `/` 不产 `//xxx`）；全链不可解析回退 Abs+Clean 并注记日志。cwd == 根 或以 根+分隔符 为前缀 → 放行，否则 `ErrWorkspaceDenied`（错误码 `workspace_denied`，403 语义）。归一判定同时封堵符号链接别名越界（别名解析后不在根内即拒）；根与 cwd 同一策略使「根尚不存在且祖先含符号链接」时同一路径归一为同一真身（同一文件系统状态下，两次归一之间链接目标变化不承诺一致）。
- 执行点：create 轮双入口强制——`SubmitSessionTurnLocal`（受理前，RemoteError）与 `runSessionTurn` create 分支（执行前防御位，hub 路径覆盖）；**send/close 沿存储绑定不重查 cwd**（内核绑定守卫已覆盖绑定漂移）。
- 互斥：**不建第二套互斥**。扩展 service 既有 wsMutex 键派生口径——会话轮（create/send，TurnSeq>0）的互斥键 = `agentid.WorkspaceID(会话 cwd)`（create 取请求 cwd；send 取内核存储 cwd），与普通任务同表同锁（普通任务键 = WorkspaceID(ArtifactRoot)）；同真实工作区的两会话、会话与普通任务同键串行，EvalSymlinks 归一使符号链接别名与真实路径同键（N05）。close 任务（TurnSeq=0）沿用 agent 键（既有行为零变化）。**启动重建占锁与执行取锁同一键派生口径**（`taskWsKey`：会话轮按会话 cwd 键、普通任务按产物根键，codex 终审必修②定案——两处异键会使重建占的锁永不释放，同根后续任务永久等待）。

## 6. 重启不确定收敛

- 时机：service 装配期（New 内、互斥表重建**之前**、任何 Reschedule 执行前）一次性扫描账本：`Task.Session != nil && TurnSeq>0 && State==accepted` → 落终态 `finished(needs_review, node_restarted_midway)`（待核对口径与 ledger.recover 对 started 条目的既有降级一致；local 条目按 MarkFinished 既有规则自确认）。started 条目已由 ledger.recover 降级（零改动）。先于重建占锁的定案（必修②）：收敛成功的条目转终态，互斥表重建按账本现态跳过——不占「永不执行」条目的锁。
- 红线：绝不自动重跑、绝不重投 CLI——落终态后即使恢复清单仍含该任务（清单在 ledger.Open 内先于本收敛生成），执行入口 MarkStarted 必败（ErrWrongState）→ 不 spawn；扫描幂等（终态条目跳过）。
- **未收敛阻断集**（codex 终审必修①定案）：收敛落盘可能失败（磁盘满等），失败条目保持 accepted，重投的 MarkStarted 会成功——「MarkStarted 必败」只在收敛成功后成立。故凡**收敛尝试过但终态未确认落盘**的受理轮一律登记进进程内阻断集（sessionID:seq → taskID），执行入口（execute 首语句 `rejectUnconvergedRecovery` 守卫）对命中阻断集的重投拒绝进入执行：
  - 命中即**就地重试收敛一次**（`RetryUncertainTurn`：对账本实物重落待核对终态）——成功即消除阻断放行（条目已终态，MarkStarted 必败仍拦住执行）；失败保持阻断，条目**保持 accepted 不执行不 spawn**（记日志；句柄若已由受理口登记则收敛，防 CancelTurn 等待悬挂），直至某次收敛成功消除；节点再重启由 RecoverUncertainTurns 重新收敛或重新阻断。
  - 拒绝执行的同时释放启动重建占有的互斥锁（防拒绝条目悬挂 seed 锁，与 §5 键口径联动）。
  - 红线不依赖「成功落终态后 MarkStarted 必败」单层防线：阻断集独立封死收敛失败路径（N06 失败注入用例实证：注入收敛第一次写盘失败 → 重投 → fake CLI 零执行、条目保持 accepted、阻断日志在）。

## 7. 错误码表（sessionErr* 增量，全部加法）

| 码 | 哨兵（sessionop） | 语义 | HTTP 意向（W01-03 投影） |
|---|---|---|---|
| turn_queue_full | ErrQueueFull | 会话非终态受理轮已达上限 | 409 |
| close_in_flight | ErrCloseInFlight | 存在非终态受理轮，拒绝关闭 | 409 |
| request_conflict | ErrRequestConflict | 同 request_id 异文 | 409 |
| workspace_denied | ErrWorkspaceDenied | cwd 越出允许根 | 403 |
| turn_cancelled_queued | （记账码） | 排队取消成立（未 spawn） | 回执码 |
| turn_cancelled_executed | （记账码） | 执行取消成立（有停止证据） | 回执码 |
| turn_cancel_outcome_unknown | （记账码） | 取消停止事实未证实（failed/待核对） | 回执码 |
| turn_already_finished | ErrTurnFinished | 轮已终态，不可取消（先到保留） | 409 |
| turn_not_found | ErrTurnUnknown | 无该轮受理记录 | 404 |
| cancel_unconfirmed | ErrCancelUnconfirmed | 取消已触发但终态未落盘（不虚报） | 500 |

旧错误码与取值零变化；取消类记账码仅出现在 sessionop 意图登记的轮（既有 task_cancel/关闭打断路径维持 user_cancelled/node_restarted_midway）。

## 8. service 接线（最小增量清单）

- `Config` 增 `SessionOps *sessionop.Service`（nil = 全部短路，零行为变化）；production 装配归 W01-03（cmd/node 属本批禁区）。
- `SubmitSessionTurnLocal` localMu 段：推导 → **AdmissionGuard（队列上限）** → create 时 **AuthorizeWorkspace** → AcceptOrigin → **BeginTurn**（登记取消 handle）→ regCancel → 释放。
- `CloseSessionLocal`：localMu 段内 **CloseGuard** → 放行内核 Close（既有幂等映射不变）。
- `execute`：会话轮互斥键按 §5 扩展；execute 入口 BindCancel（ce.trigger）；hub 受理点（AcceptFenced 相邻）同步登记句柄；取消/关闭弃队分支对 sessionop 意图轮走 `finishCancelledSessionTurnBeforeRun`（queued 记账），非意图轮沿既有 finishCancelledBeforeRun 并收敛句柄；MarkStarted 失败与各弃队早退对会话轮收敛句柄（AbortTurn，防 CancelTurn 等待悬挂）；取消终态分类在 runSessionTurn 包装器内依内核证据记账，**句柄收敛在终态落盘点之后**（先收敛会使 execute 收尾的意图复查查空句柄，已分类取消终态被既有 cancelledResult 改写——实现期实证修正），sessionop 意图轮不再被既有改写覆盖。
- `runSessionTurn`：拆为包装器（收敛+分类）与原实现体（行为不变）；kernel 证据（turn 指针）随内部返回值传递。

## 10. 已知限制（如实移交 W01-03）

1. hub 下发会话轮不经 node 侧队列/关闭防护判定（hub 落库前判定归 W01-03；node 计数含两类来源）。
2. request_id/取消/队列的新错误码在 localapi 的 HTTP 状态码投影未接线（localapi 属本批禁区；服务层以 RemoteError.Code 交付，409/403 映射表已在 §7 给定）。
3. cmd/node 装配 Config.SessionOps 归 W01-03；本批 production 未接线时全部新能力短路（行为同今天）。
4. 取消句柄注册窗口已闭合：hub 受理点（AcceptFenced 相邻语句）与本地受理互斥段均同步登记句柄，execute 入口仅补绑触发开关；CancelTurn 对「在途但句柄未登记」仍保留 bounded 等待兜底，超时如实拒绝（不虚报），可重试。
5. 会话轮依赖挂载路径（inputs.go，本批禁区）弃队不收敛句柄——会话轮无 depends_on 投递面，实际不可达；W01-03 放开该路径时须同步收敛句柄。
